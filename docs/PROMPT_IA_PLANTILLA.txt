OBJETIVO
Generar una PLANTILLA WORD (.docx) que se parezca lo más posible al reporte original y que cumpla EXACTAMENTE el lenguaje del "modo layout" de nuestro compilador. El equipo de Informática la mejorará después. Si dudas entre parecido visual y validez, elige validez.

El compilador lee el Word completo (encabezado, cuerpo y pie) y lo imprime con un motor PDF propio:
- las tablas del Word se dibujan tal cual, con los bordes que tenga cada celda;
- una tabla con {{COLUMN:...}} es una TABLA DE DATOS: su fila de marcadores se repite una vez por registro;
- los valores salen de consultas SQL con nombre (una por bloque del reporte), que Informática escribe aparte.

---------------------------------------------------------------------
1. REGLAS OBLIGATORIAS DEL DOCX (si se incumple una, el compilador lo rechaza)
---------------------------------------------------------------------
Página y zonas:
- Papel A4 (21 x 29,7 cm), vertical u horizontal. Una sola sección.
- El encabezado y el pie de Word pueden tener párrafos y tablas de maquetación; se repiten en cada página.
- Sin encabezado/pie distinto para la primera página o páginas pares.

Marcadores (los únicos que existen; cualquier otra cosa entre {{ }} es error):
- {{REPORT_TITLE}}: título del reporte (normalmente en el encabezado de Word, centrado).
- {{FIELD:CONSULTA.COLUMNA}}: un valor de la primera fila de una consulta (datos de cabecera, grupo maestro, resúmenes). En cualquier párrafo o celda.
- {{FIELD:NOMBRE}}: un texto fijo o un parámetro (por ejemplo el nombre del sistema o el código del reporte).
- {{COLUMN:CONSULTA.COLUMNA}}: solo en la fila que se repite de una tabla de datos.
- {{SUM:CONSULTA.COLUMNA}}: solo en las filas de totales de una tabla de datos (debajo de la fila que se repite).
- {{APP_USER}}: usuario que imprime. {{GENERATED_AT}}: fecha/hora de impresión.
- {{PAGE}} y {{PAGES}}: número de página y total. SOLO en el encabezado o el pie de Word.
- Formato opcional con barra vertical al final: {{FIELD:ALUMNO.FECHA|DD/MM/YYYY}}, {{COLUMN:CUOTAS.IMPORTE|FM999G999G990D00}}, {{GENERATED_AT|HH:MI:SS AM}}. Use máscaras TO_CHAR de Oracle.
- CONSULTA, COLUMNA y NOMBRE: mayúsculas, empiezan con letra, solo A-Z, 0-9 y _, máximo 30 caracteres.
- Todo el marcador con el mismo formato (no ponga parte en negrita y parte no). Sin espacios dentro de las llaves.

Tablas de datos (una por cada bloque repetitivo del original):
- Filas ANTES de la fila de marcadores = cabecera (por ejemplo una banda gris con el título del bloque y una fila con los títulos de columna). Se repiten en cada página.
- UNA fila con {{COLUMN:...}}: cada celda tiene un marcador o queda vacía; todos de la MISMA consulta.
- Filas DESPUÉS = totales, con {{SUM:...}} de la misma consulta.
- Nada de tablas de datos dentro del encabezado o pie de Word.

Tablas de maquetación (cuadrículas, recuadros, bandas, el resumen final, el encabezado y el pie):
- Cualquier tabla sin {{COLUMN:...}}. Use bordes por celda: negro para líneas visibles, BLANCO o "sin borde" para separaciones invisibles. Rellenos de color permitidos.
- Se permite combinar celdas en HORIZONTAL. Prohibido combinar en vertical y anidar tablas.
- Cada fila debe ocupar todas las columnas de la tabla.

Texto:
- El texto de una celda NO salta de línea solo: si necesita varias líneas, use saltos de línea manuales (Mayús+Intro). Haga las columnas lo bastante anchas.
- Fuente recomendada: Arial (todo se imprime como Helvetica). Negrita y cursiva sí; subrayado y tachado no se imprimen.
- Las celdas y párrafos vacíos también ocupan alto: deje su marca de párrafo en 2 a 6 pt.

Prohibido en cualquier parte: imágenes, logos, formas, cuadros de texto, WordArt, SmartArt, gráficos, campos de Word (número de página automático, fecha automática), controles de contenido, comentarios, notas al pie, control de cambios, texto oculto, hipervínculos, macros, ecuaciones, símbolos insertados.

---------------------------------------------------------------------
2. CÓMO TRADUCIR EL REPORTE ORIGINAL
---------------------------------------------------------------------
a) Una CONSULTA por bloque de datos del original (un Group de Oracle Reports). Nómbrela con el nombre del grupo sin el prefijo G_ (G_ALUMNO -> ALUMNO) o, sin captura de diseño, con el tema del bloque (CUOTAS, PAGOS, MORAS, RESUMEN).
b) Datos que aparecen una sola vez (cabecera, datos del cliente/alumno/préstamo): tabla de maquetación tipo cuadrícula con pares etiqueta/valor:
   - columnas alternas etiqueta | valor; borde BLANCO entre etiqueta y valor; líneas negras donde el original tiene recuadros;
   - valores con {{FIELD:CONSULTA.COLUMNA}}; importes alineados a la derecha con máscara FM999G999G990D00.
c) Bloques repetitivos: una tabla de datos cada uno, con su banda de título gris (celda combinada), fila de títulos de columna en recuadros y, si el original tiene totales, fila de totales con {{SUM:...}} en celdas grises con recuadro.
   - Si el original deja huecos entre columnas, use columnas vacías (sin título ni marcador).
d) Recuadros de resumen (por ejemplo "Saldo pendiente"): tabla de maquetación centrada con borde exterior, filas etiqueta | signo | valor y valores con {{FIELD:RESUMEN.COLUMNA}}.
e) Encabezado de página del original (sistema, módulo, código, fecha, hora, usuario, título) -> encabezado de Word con una tabla invisible de 3 celdas y un párrafo centrado con {{REPORT_TITLE}}. Textos fijos como {{FIELD:SISTEMA}}, {{FIELD:CODIGO}}.
f) Pie del original ("Generado por ...", "Pág. X de Y") -> pie de Word con {{APP_USER}}, {{PAGE}} y {{PAGES}} (en celdas con recuadro si el original los muestra en casillas).
g) No inventes datos ni bloques que no estén en las capturas.

---------------------------------------------------------------------
3. NOMBRES TÉCNICOS
---------------------------------------------------------------------
- Con captura de diseño: COLUMNA = nombre del campo de Oracle sin F_, CF_, CS_ o CP_ y sin el sufijo numérico si no hace falta (F_nom_alumno1 -> NOM_ALUMNO). Si dos quedan iguales, conserve el número.
- Si un nombre está cortado en la captura, use el más probable.
- Sin captura de diseño: derive el nombre de la etiqueta (Imp. Cuota -> IMP_CUOTA; N° Docum -> NRO_DOC; Año -> ANIO, sin Ñ ni tildes).
- Evite palabras reservadas de Oracle como COLUMNA (DATE, LEVEL, NUMBER, ORDER, USER, SIZE...): use FECHA, NIVEL, NUMERO, etc.

"""Genera una plantilla Word para el compilador APEX en MODO LAYOUT.

Requiere: pip install python-docx
Edite solo la función diseno(); las funciones de ayuda aplican las reglas técnicas.
"""
import io
import re
import zipfile

from docx import Document
from docx.enum.text import WD_ALIGN_PARAGRAPH
from docx.oxml import OxmlElement
from docx.oxml.ns import qn
from docx.shared import Mm, Pt, RGBColor

SALIDA = "REPORTE.docx"
FUENTE = "Arial"
DINERO = "FM999G999G990D00"
NEGRO, BLANCO, GRIS, BANDA, CLARO = "000000", "FFFFFF", "D9D9D9", "BFBFBF", "D9D9D9"
SIN_CAMBIO = object()


# ------------------------------------------------------------ ayudas (no editar)
def texto(parrafo, contenido, tam=7, negrita=False, cursiva=False, color=NEGRO):
    r = parrafo.add_run(contenido)
    r.font.name = FUENTE
    r.font.size = Pt(tam)
    r.font.bold = negrita
    r.font.italic = cursiva
    r.font.color.rgb = RGBColor.from_string(color)
    fuentes = r._element.get_or_add_rPr().get_or_add_rFonts()
    fuentes.set(qn("w:ascii"), FUENTE)
    fuentes.set(qn("w:hAnsi"), FUENTE)
    return r


def ajustar(parrafo, alinear="L", tam_marca=None):
    parrafo.alignment = {"L": WD_ALIGN_PARAGRAPH.LEFT, "C": WD_ALIGN_PARAGRAPH.CENTER,
                         "R": WD_ALIGN_PARAGRAPH.RIGHT}[alinear]
    parrafo.paragraph_format.space_before = Pt(0)
    parrafo.paragraph_format.space_after = Pt(0)
    if tam_marca is not None:                      # la marca de párrafo vacía también ocupa alto
        ppr = parrafo._p.get_or_add_pPr()
        rpr = OxmlElement("w:rPr")
        sz = OxmlElement("w:sz")
        sz.set(qn("w:val"), str(int(tam_marca * 2)))
        rpr.append(sz)
        ppr.append(rpr)
    return parrafo


def celda_texto(celda, contenido, alinear="L", tam=7, negrita=False, cursiva=False):
    """contenido: texto (\\n = salto de línea manual) o lista [(texto, {"tam":..,"negrita":..,"cursiva":..}), ...]."""
    parrafo = ajustar(celda.paragraphs[0], alinear, tam)
    partes = contenido if isinstance(contenido, list) else [(contenido, {})]
    for fragmento, opciones in partes:
        lineas = fragmento.split("\n")
        for i, linea in enumerate(lineas):
            r = texto(parrafo, linea, opciones.get("tam", tam), opciones.get("negrita", negrita),
                      opciones.get("cursiva", cursiva))
            if i < len(lineas) - 1:
                r.add_break()
    return parrafo


def borde(celda, arriba=SIN_CAMBIO, abajo=SIN_CAMBIO, izq=SIN_CAMBIO, der=SIN_CAMBIO):
    """Cada lado: None = sin borde; (ancho_pt, "RRGGBB") = borde (use BLANCO para un borde invisible)."""
    tcpr = celda._tc.get_or_add_tcPr()
    viejo = tcpr.find(qn("w:tcBorders"))
    actuales = {}
    if viejo is not None:
        actuales = {hijo.tag: hijo for hijo in viejo}
        tcpr.remove(viejo)
    nodo = OxmlElement("w:tcBorders")
    for lado, valor in (("top", arriba), ("left", izq), ("bottom", abajo), ("right", der)):
        if valor is SIN_CAMBIO:
            if qn(f"w:{lado}") in actuales:
                nodo.append(actuales[qn(f"w:{lado}")])
            continue
        el = OxmlElement(f"w:{lado}")
        if valor is None:
            el.set(qn("w:val"), "nil")
        else:
            el.set(qn("w:val"), "single")
            el.set(qn("w:sz"), str(int(valor[0] * 8)))
            el.set(qn("w:space"), "0")
            el.set(qn("w:color"), valor[1])
        nodo.append(el)
    tcpr.insert_element_before(nodo, "w:shd", "w:noWrap", "w:tcMar", "w:textDirection", "w:tcFitText",
                               "w:vAlign", "w:hideMark")


def caja(celda, ancho=0.5, color=NEGRO):
    borde(celda, arriba=(ancho, color), abajo=(ancho, color), izq=(ancho, color), der=(ancho, color))


def relleno(celda, color):
    shd = OxmlElement("w:shd")
    shd.set(qn("w:val"), "clear")
    shd.set(qn("w:color"), "auto")
    shd.set(qn("w:fill"), color)
    celda._tc.get_or_add_tcPr().insert_element_before(shd, "w:noWrap", "w:tcMar", "w:textDirection",
                                                      "w:tcFitText", "w:vAlign", "w:hideMark")


def tabla(contenedor, filas, anchos_mm, centrada=False, margen_mm=0.8):
    """Tabla sin ningún borde; los bordes se ponen celda por celda con borde() o caja()."""
    if contenedor.__class__.__name__ == "Document":
        t = contenedor.add_table(rows=filas, cols=len(anchos_mm))
    else:
        t = contenedor.add_table(rows=filas, cols=len(anchos_mm), width=Mm(sum(anchos_mm)))
    tblpr = t._tbl.tblPr
    if centrada:
        jc = OxmlElement("w:jc")
        jc.set(qn("w:val"), "center")
        tblpr.insert_element_before(jc, "w:tblCellSpacing", "w:tblInd", "w:tblBorders", "w:shd",
                                    "w:tblLayout", "w:tblCellMar", "w:tblLook")
    else:
        ind = OxmlElement("w:tblInd")
        ind.set(qn("w:w"), "0")
        ind.set(qn("w:type"), "dxa")
        tblpr.insert_element_before(ind, "w:tblBorders", "w:shd", "w:tblLayout", "w:tblCellMar", "w:tblLook")
    bordes = OxmlElement("w:tblBorders")
    for lado in ("top", "left", "bottom", "right", "insideH", "insideV"):
        el = OxmlElement(f"w:{lado}")
        el.set(qn("w:val"), "nil")
        bordes.append(el)
    tblpr.insert_element_before(bordes, "w:shd", "w:tblLayout", "w:tblCellMar", "w:tblLook")
    mar = OxmlElement("w:tblCellMar")
    for lado, valor in (("top", 0), ("left", margen_mm), ("bottom", 0), ("right", margen_mm)):
        el = OxmlElement(f"w:{lado}")
        el.set(qn("w:w"), str(int(valor * 1440 / 25.4)))
        el.set(qn("w:type"), "dxa")
        mar.append(el)
    tblpr.insert_element_before(mar, "w:tblLook")
    t.autofit = False
    for i, ancho in enumerate(anchos_mm):
        t._tbl.tblGrid.gridCol_lst[i].set(qn("w:w"), str(int(ancho * 1440 / 25.4)))
        for fila in t.rows:
            fila.cells[i].width = Mm(ancho)
    for fila in t.rows:
        for celda in fila.cells:
            ajustar(celda.paragraphs[0], tam_marca=6)
    return t


def espacio(contenedor, tam=5):
    ajustar(contenedor.add_paragraph(), tam_marca=tam)


def tabla_datos(doc, titulo, columnas_titulo, encabezados, marcadores, anchos, alineaciones, totales=None):
    """Tabla de datos: banda de título, fila de encabezados, fila que se repite y fila de totales.

    marcadores: un {{COLUMN:CONSULTA.COLUMNA}} por celda ("" = celda vacía).
    totales: {índice_de_columna: "{{SUM:CONSULTA.COLUMNA|máscara}}"}.
    """
    t = tabla(doc, 4 if totales else 3, anchos)
    banda = t.rows[0].cells[0].merge(t.rows[0].cells[columnas_titulo - 1])
    relleno(banda, BANDA)
    celda_texto(banda, titulo, cursiva=True, tam=7.5)
    for i, encabezado in enumerate(encabezados):
        if encabezado:
            caja(t.rows[1].cells[i])
            celda_texto(t.rows[1].cells[i], encabezado, "C", cursiva=True)
        if marcadores[i]:
            borde(t.rows[2].cells[i], abajo=(0.25, CLARO))
            celda_texto(t.rows[2].cells[i], marcadores[i], alineaciones[i])
    for i, marcador in (totales or {}).items():
        relleno(t.rows[3].cells[i], GRIS)
        caja(t.rows[3].cells[i])
        celda_texto(t.rows[3].cells[i], marcador, "R")
    espacio(doc)
    return t


def preparar_documento(horizontal=False):
    doc = Document()
    s = doc.sections[0]
    ancho, alto = Mm(210), Mm(297)                 # A4 (python-docx usa Carta por defecto)
    if horizontal:
        from docx.enum.section import WD_ORIENT
        s.orientation = WD_ORIENT.LANDSCAPE
        ancho, alto = alto, ancho
    s.page_width, s.page_height = ancho, alto
    s.left_margin = s.right_margin = Mm(15)
    s.top_margin, s.bottom_margin = Mm(26), Mm(30)
    s.header_distance, s.footer_distance = Mm(6), Mm(10)
    for zona in (s.header, s.footer):
        zona.is_linked_to_previous = False
        zona._element.remove(zona.paragraphs[0]._p)
    return doc


def cerrar_zona(zona):
    ajustar(zona.add_paragraph(), tam_marca=2)    # Word exige un párrafo final


def guardar(doc, ruta):
    """Guarda quitando la parte customXml que python-docx incluye y el compilador rechaza."""
    buffer = io.BytesIO()
    doc.save(buffer)
    origen = zipfile.ZipFile(io.BytesIO(buffer.getvalue()))
    with zipfile.ZipFile(ruta, "w", zipfile.ZIP_DEFLATED) as destino:
        for nombre in origen.namelist():
            if nombre.lower().startswith("customxml/"):
                continue
            datos = origen.read(nombre)
            if nombre in ("word/_rels/document.xml.rels", "[Content_Types].xml"):
                txt = datos.decode("utf-8")
                txt = re.sub(r"<Relationship [^>]*customXml[^>]*/>", "", txt)
                txt = re.sub(r'<Override PartName="/customXml/[^>]*/>', "", txt)
                datos = txt.encode("utf-8")
            destino.writestr(nombre, datos)


# ------------------------------------------------------------ DISEÑO (reemplazar completo)
def diseno():
    doc = preparar_documento(horizontal=False)
    s = doc.sections[0]

    # Encabezado de Word (se repite en cada página): tabla invisible de 3 celdas + título.
    cab = tabla(s.header, 1, [60, 60, 60], margen_mm=0)
    celda_texto(cab.rows[0].cells[0], "{{FIELD:SISTEMA}}\n{{FIELD:CODIGO}}", tam=6)
    celda_texto(cab.rows[0].cells[2], "{{GENERATED_AT|DD/MM/YYYY}}\n{{GENERATED_AT|HH:MI:SS AM}}\n{{APP_USER}}",
                "R", tam=6)
    texto(ajustar(s.header.add_paragraph(), "C"), "{{REPORT_TITLE}}", tam=10)
    cerrar_zona(s.header)

    # Pie de Word: línea superior, usuario y "X DE Y".
    pie = tabla(s.footer, 1, [78, 5, 7, 5, 85], margen_mm=0.5)
    c = pie.rows[0].cells
    for celda in c:
        borde(celda, arriba=(1.5, NEGRO))
    celda_texto(c[0], "Generado por {{APP_USER}}")
    caja(c[1]); celda_texto(c[1], "{{PAGE}}", "C")
    celda_texto(c[2], "DE", "C")
    caja(c[3]); celda_texto(c[3], "{{PAGES}}", "C")
    cerrar_zona(s.footer)

    # Cabecera del grupo maestro: cuadrícula etiqueta/valor; borde blanco entre etiqueta y valor.
    g = tabla(doc, 3, [30, 60, 30, 60])
    banda = g.rows[0].cells[0].merge(g.rows[0].cells[3])
    relleno(banda, GRIS)
    caja(banda, 0.75)
    celda_texto(banda, [("Cliente : {{FIELD:MAESTRO.CODIGO}}   ", {"tam": 8.5}),
                        ("{{FIELD:MAESTRO.NOMBRE}}", {"tam": 8.5, "cursiva": True})])
    pares = [("Fecha :", "{{FIELD:MAESTRO.FECHA|DD/MM/YYYY}}", "Importe :", "{{FIELD:MAESTRO.IMPORTE|%s}}" % DINERO),
             ("Estado :", "{{FIELD:MAESTRO.ESTADO}}", "Saldo :", "{{FIELD:MAESTRO.SALDO|%s}}" % DINERO)]
    for f, (e1, v1, e2, v2) in enumerate(pares, start=1):
        ultima = f == len(pares)
        for col, (contenido, alinear) in enumerate(((e1, "L"), (v1, "L"), (e2, "L"), (v2, "R"))):
            celda = g.rows[f].cells[col]
            celda_texto(celda, contenido, alinear, tam=7.5)
            borde(celda, izq=(0.75, NEGRO) if col in (0, 2) else (0.5, BLANCO),
                  der=(0.75, NEGRO) if col == 3 else (0.5, BLANCO) if col in (0, 2) else None,
                  abajo=(0.75, NEGRO) if ultima else None)
    espacio(doc, 6)

    # Tabla de datos (una por grupo repetitivo del reporte original).
    tabla_datos(doc, "MOVIMIENTOS", 3,
                ["Fecha", "Documento", "Concepto", "Importe"],
                ["{{COLUMN:MOVIMIENTOS.FECHA|DD/MM/YYYY}}", "{{COLUMN:MOVIMIENTOS.DOCUMENTO}}",
                 "{{COLUMN:MOVIMIENTOS.CONCEPTO}}", "{{COLUMN:MOVIMIENTOS.IMPORTE|%s}}" % DINERO],
                [20, 30, 80, 25], ["C", "C", "L", "R"],
                {3: "{{SUM:MOVIMIENTOS.IMPORTE|%s}}" % DINERO})
    return doc


if __name__ == "__main__":
    guardar(diseno(), SALIDA)
    print("Generado:", SALIDA)
